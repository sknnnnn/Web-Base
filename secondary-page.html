PÁGINA SECUNDARIA

Ejemplo de página secundaria.

Esta página demuestra cómo reutilizar el header, el footer y el sistema de componentes de Web-Base en una segunda página real, sin agregar ningún componente nuevo.

CONTENIDO

Composición con primitives existentes

Todo lo que ves en esta página usa las mismas clases que ya existen en style.css: contenedores, secciones, tipografía, cards y botones. No se creó ningún componente nuevo para esta página.

Reutilizable

El mismo header, footer y sistema de navegación de la página principal, repetidos sin duplicar lógica.

Sin includes

El markup se repite directamente en cada archivo HTML, de forma deliberada, sin build step ni templating.

Navegación real

Esta página y la principal se enlazan entre sí con links reales, no con anclas.
